Paste this where you want it

Upload this file once to your hosting as /booking-widget/index.html, then paste the snippet into any page. It sizes itself to fit.

Turn the holiday line off any time by adding &urgency=off to the link.

<iframe id="glowpro-booking" src="/booking-widget/?embed=1"
  title="Book your free consultation with Glow Pro"
  loading="lazy" style="display:block;width:100%;max-width:480px;
  height:900px;margin:0 auto;border:0;background:transparent"></iframe>
<script>
addEventListener('message', function (e) {
  var f = document.getElementById('glowpro-booking');
  if (f && e.source === f.contentWindow && e.data
      && e.data.type === 'gpw-height') {
    f.style.height = e.data.h + 'px';
  }
});
</script>
